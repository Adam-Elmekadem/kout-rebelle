# Rebelle — Shift / 01

An original cold-weather streetwear brand chapter for [Kout Project](../). The site includes a cinematic campaign landing page, four-piece collection, category filters, quick-view product details, size selection, and a demo bag.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. Run `npm run check` and `npm run build` before publishing.

## Brand files

- [Brand system](./BRAND_SYSTEM.md)
- [Image prompts](./IMAGE_PROMPTS.md)
- `public/images/`: original campaign and product concept images, optimized as WebP
